# Конвертер валют

Веб-приложение для конвертации валют на основе курсов ЦБ РФ

## Запуск
Открыть `index.html` в любом браузере. Сервер не требуется

## Функции
- Конвертация между RUB, USD, EUR, UAH, CNY, BYN
- Автозагрузка курсов из API ЦБ РФ
- Кэширование курсов (localStorage)
- История последних 10 операций
- Валидация ввода

## Структура
- `index.html` — разметка
- `style.css` — стили
- `script.js` — логика (загрузка курсов, конвертация, история)

## API
Данные берутся с `https://www.cbr-xml-daily.ru/daily_json.js`
